# 모델 평가 보고서

이 문서는 `ml/reports/backtest-openfootball.json`(전체 결과)에서 생성했습니다. 다시 만들려면:

```bash
python -m edge_ingestion.cli backtest --tune \
  --leagues en.1,en.2,de.1,de.2,es.1,it.1,fr.1,nl.1,pt.1,at.1 \
  --out ml/reports/backtest-openfootball.json
```

EPL(첫 번째 리그)은 튜닝·보정·승격 판단까지 자세히 평가하고, 나머지 리그는 **같은 운영 모델(v0.2.0)을
그대로** 적용해 테스트 구간만 채점합니다. 리그별로 파라미터를 따로 맞추지 않았습니다.

## 데이터와 절차
- **데이터**: openfootball/football.json, 2018-19~2025-26 실제 결과(퍼블릭 도메인). EPL 3040경기를 자세히
  평가하고, 같은 기간 9개 리그(아래 표)를 추가로 채점했습니다. 팀 이름 표기가 시즌마다 달라("Manchester City" / "Manchester City FC") 정규화한 뒤,
  시즌마다 20팀·380경기·중복 없음을 검사했습니다.
- **배당 없음**: 이 데이터에는 배당이 없어서 **시장 확률과의 비교는 이 보고서에 포함되지 않았습니다.**
  football-data.co.uk CSV(종가 배당 포함)를 받으면 `--source football-data --data-dir <폴더>`로 같은
  비교를 실행할 수 있습니다. 시장보다 정확한지는 아직 **측정하지 않았습니다.**
- **분할**: 워밍업 < 2020-21 (학습에만 사용), 검증 2020-21 .. < 2023-24
  (파라미터 선택·보정), 테스트 >= 2023-24 (선택을 고정한 뒤 한 번만 채점, 승격 판단에만 사용).
- **walk-forward**: 매주 재학습하며, 각 경기는 그 주 시작 이전에 킥오프한 경기만으로 학습한 모델이
  예측합니다(테스트로 강제). 모든 모델은 같은 경기 집합으로 채점합니다.
- **지표**: log loss(낮을수록 좋음, 기준 모델 ≈ 1.07), Brier(0~2), RPS(순서형, 0~1), 적중률(최고 확률
  결과), ECE(보정 오차). 신뢰구간은 경기 단위 부트스트랩(2,000회)입니다.

## 선발 명단 변수 실험 (2단계, 아직 서비스 모델에 반영하지 않음)

`python -m edge_ingestion.cli backtest-lineups --out ml/reports/backtest-lineups-statsbomb.json`

- **데이터**: StatsBomb open data 2015/16 시즌(Premier League 379, La Liga 379, Serie A 380, Ligue 1 377경기).
  경기마다 양 팀 선발 11명과 선수별 출전 시간이 있습니다. 연구용 무료 데이터이며, 결과를 공개할 때는
  출처(StatsBomb)를 밝혀야 합니다.
- **변수**: 팀의 최근 10경기 출전 시간 비중으로 선수별 비중을 정하고, 오늘 선발 11명의 비중 합을 평소
  주전 11명의 비중 합으로 나눈 값(1.0 = 평소 주전 그대로). 이 값으로 운영 모델의 기대 득점을 조정합니다:
  `log λ' = log λ + β(S_자기팀 − 1) − γ(S_상대 − 1)`.
- **절차**: 리그마다 시간순으로 앞 26%는 학습 전용, 60%까지 검증(β·γ만 추정), 나머지를 한 번만 채점해
  4개 리그를 합산했습니다. 한 시즌 데이터라 기본 모델이 매 시즌 처음부터 학습하는 조건입니다(실제
  운영보다 불리한 조건).
- **추정값**: β = 0.21, γ = 0.18 (검증 488경기). 주전 비중이 0.8로 떨어지면 자기 팀 기대 득점 약 −4%, 상대
  기대 득점 약 +4%. 평균 선발 비중은 0.85였습니다.

  세 경우 모두 95% CI가 0을 포함해 통계적으로 확정되지 않았습니다.** 리그별로는 La Liga·Ligue 1·Serie A에서
  좋아지고 Premier League에서는 약간 나빠졌습니다.
- **분할 민감도**: 처음 고정 분할(앞 100경기/230경기)로 돌렸을 때는 −0.0019 [−0.0044, +0.0005]로 기준(0.002)에
  0.0001 못 미쳤습니다. 결과가 기준선 근처에 있다는 뜻이므로, 서비스 반영(3단계) 전에 더 큰 표본으로 다시
  재는 것을 권합니다: API-Football 과거 명단으로 `edge backfill-appearances` → `edge backtest-lineups --source db`.
