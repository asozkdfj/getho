## shadow-v1에서 반드시 구분할 것

- 기간은 2026-10-20~12-14, 최소 완료 1,500경기. 56일 평균 약 26.8경기/일의
  비교 가능한 완료 표본이 필요하다. 이는 단순 필요량이며 확보 가능성이나 통계적 검정력을 보장하지 않는다.
  부족하면 inconclusive로 남기고 기간을 사후 연장하지 않는다.
- 실제 결정은 09:00 이후 첫 요청/파이프라인 시각이다. 같은 시각의 세 모델 비교는 가능하지만
  이를 정확히 09:00 고정 모델 성과로 부르면 안 된다. 실제 시각과 09:00 차이를 기록한다.
  09:00 고정 정책이 필요하면 별도 policy/protocol로 등록하고 v1과 섞지 않는다.
- 현재 등록은 **결정일 단위** bootstrap이다. 사용자가 요구한 주 단위 검증과 같지 않다.
  일 단위 등록 기준은 보존하고 주 단위 CI를 보조 분석으로 함께 제출한다. 두 결과가
  다르면 불확실성을 보고하며 유리한 CI만 선택하지 않는다. 8주 자체도 제한적인 cluster 수다.
- 전체 리그가 주 분석이고 픽 범위는 부 분석이다. 전체 리그 개선을 EPL 개선으로 주장하지 않는다.
  EPL/검증된 리그의 별도 결과와 표본을 함께 보고한다. 시즌별 표본 부족도 명시한다.
- `shadow_report`는 provisional/inconclusive에서도 `decisions` 계산값을 반환한다.
  함수 문서상 final에서만 의미가 있으므로 호출자는 **status가 final인지 먼저 검사**해야 한다.
  중간 운영 대시보드는 성공률/승격 신호 대신 수집 상태만 제시하는 편이 적합하다.
  이번에는 이 동작을 새로운 재현 결함으로 분류하지 않았고 코드 읽기에서 확인한 사용 제약이다.
- 당시 기록이 아예 없는 날은 제외 경기 행과 다르다. 행 수만으로 기록 누락을 알 수 없으므로
  실행 이력/예정 실행일을 대조해야 한다. 무경기일·정상 무추천·수집 장애를 분리한다.

## 선수/피로 후보 실험 범위

[paired 분석](2026-10-19-model-paired-followup.md)의 고정 676경기에는 양 팀 결장 정보가 34개뿐이다.
이 자료만으로 변수 효과를 적합하거나, 결측을 출전 가능으로 대치하지 않는다.
이미 관측한 표본을 최종 평가로 재사용하지 않는다.

최소 연구 후보는 F(선수별 최근 출전 부담/휴식)와 P(당시 가용 선수 전력)를 별개로 추가한다.
원래 운영 모델 대비 개선뿐 아니라 시장 대비 추가 정보를 주는지도 평가한다.
오래된 기록을 지금 백필하는 것은 학습 연구에 유용하지만 당시 실제 관측됐다고 표시할 수 없다.
시점 가정 연구와 실제 운영 시점 검증을 별도 정책으로 유지한다.
전술·이동·멘탈리티는 입력 정의와 관측 이력이 마련된 후 검토하며 이번 실험에 임의 점수를 넣지 않는다.

새 후보의 정확한 학습/선택/후속 날짜와 최소 표본은 데이터 커버리지 확인 후 **결과 확인 전에**
별도 등록해야 한다. 현 문서는 후보 등록이나 학습 완료 선언이 아니라 착수 조건 리뷰다.
