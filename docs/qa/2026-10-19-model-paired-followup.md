# 모델 개선 후속 분석 — 2026-10-19, Codex

## 결론

고정한 동일 676경기에서는 시장 확률이 운영 모델과 25% 운영 + 75% 시장 혼합보다 좋다.
그러나 이는 이미 본 10/17~18 표본의 추가 분석이지 새 미관측 평가가 아니다.
현재 판정은 **개선 후보 확인 / 모델 교체 INCONCLUSIVE**다.
운영 모델·가중치·선정 정책은 변경하지 않았다.

## 실제 실행과 재현

기존 실데이터 읽기 전용 감사의 manifest를 그대로 고정했다. 이번 실행은 DB/API를 호출하지 않았다.

전체 3,364행 중 공통 조건 충족 943, 완료 676, 미완료 267, 제외 2,421.
원본 경기별 자료는 로컬 `.cache/2026-10-19-decision-market-final.jsonl`에 보존하며
공유 저장소에는 분석 코드와 집계 JSON만 올린다. 원본 없이 동일 수치 재계산은 불가능하다.
향후 DB를 다시 조회하면 결과/일정 변경 때문에 다른 해시·표본이 나올 수 있다.

288경기에서 낮았다. 평균 paired 차이는 -0.025307이다. 두 의사결정일 각각에서도
시장 Log Loss가 가장 낮았다. ECE는 운영 모델이 더 낮아 모든 확률 지표에서 시장이
우세하다고 말할 수 없다. ECE는 최대 확률의 10개 고정 구간 기준이며 작은 표본에 민감하다.

158개 리그 ID가 섞여 있고 각 리그 완료 표본은 모두 20경기 미만이다.
리그별 표는 JSON에 있지만 EPL 일반화나 리그별 우열의 증거로 삼지 않는다.
시즌 식별자가 없어 시즌별 비교는 미실행이다.
의사결정일은 2일, ISO 주는 1개다. 주 단위 95% CI는 **산출 보류**했다.
도구는 8주 미만이면 CI를 비워 두며, 8주는 도구의 보고 최소 조건일 뿐 채택 기준이 아니다.
8주 이상은 주 전체를 paired 재표집하고 경기 수로 가중한다(4,000회, seed 20261019).
어떤 경우에도 이 도구만으로 승격을 승인하지 않는다.

60% 이상 확률 구간의 서술 집계도 저장했다. 운영 86/676경기, 시장 120/676경기,
혼합 113/676경기로 서로 다른 경기 집합이다. 이 구간 적중률을 동일 표본 비교나
하루 최대 1개인 오늘의 픽 성적으로 인용하지 않는다.

## 선수·피로 변수 추가 판단

이 676경기에서 오전 9시 양 팀 결장 정보가 저장된 경기는 **34개**, 양 팀 공식 선발은 **0개**다.
저장 존재는 완전한 커버리지나 건강 상태를 증명하지 않는다. 최신 PR #16의 과거 선수
기록 필터/결장 파싱 결함도 수정 전이다. 따라서 선수 효과 계수를 이 표본으로 학습하거나
미수집을 정상 출전으로 채우지 않았다. 추가 변수의 paired 예측이 없어 성능 증분은 미측정이다.

기존 `ml/reports/backtest-fatigue-england.json`를 확인한 결과, 팀 일정 혼잡 후보는
검증 개선 -0.0000436, 후속 개선 -0.0012309로 기존 gate 실패다(양수가 개선).
이는 기존 산출물 확인이며 이번에 전체 피로 백테스트를 다시 돌린 결과는 아니다.
변수를 늘리면 자동으로 좋아진다고 가정할 수 없다.

## Claude 구현 요청 — 독립 평가 가능한 최소 실험

1. 기존 shadow-v1의 기간·가중치·판정 기준을 유지한다. 같은 `decision_at`에 운영,
   시장 단독, 고정 혼합을 append-only 기록한다. 09:00 고정 평가와 첫 요청 시각 평가는
   별도 정책 ID로 분리한다. 기존 구간에 맞춰 가중치를 다시 고르지 않는다.
2. 선수/피로 후보는 별도 연구 버전으로 만든다. 공통 비교군은 시장과 운영 모두다.
   시장을 이미 반영한 모델에 새 변수가 시장보다 추가 정보를 주는지도 확인한다.
3. 후보 F: 양 팀 최근 7/14/28일 실제 출전 부담, 휴식 시간, 연장전. 선수 기록이
   부족하면 팀 경기 수 대리값과 구분하고 모든 대회 커버리지·결측 플래그를 기록한다.
   이동 거리/포메이션/멘탈리티는 현재 시점 이력과 입력 정의가 없어 이번 후보에서 제외한다.
4. 후보 P: 결정 시각 이전 결장·출전 불투명 정보와 이전 출전 시간으로 예상 가용 전력을
   만든다. 공식 선발은 선발 발표 후 별도 정책에서만 평가한다. 최근 경기 선택뿐 아니라
   개별 출전 행의 `created_at <= decision_at`을 적용한다.
5. F, P 각각을 독립 추가하고 F+P는 검증 구간에서 사전 선택한 경우만 후속 평가한다.
   학습/보정/후보 선택/최종 평가 구간을 시간순 분리한다. 계수·대치·표준화도 학습 구간만
   사용한다. 현재 676경기는 이미 관측한 탐색 자료이므로 최종 평가로 재사용하지 않는다.
6. `PREDICTION_CONTRACT_V1.md`의 baseline/candidate JSONL, 전체 manifest와 제외 사유,
   입력/결과 가용 시각, 코드 SHA·파라미터·원본 해시를 제출한다. 새 후보의 수치 확인 전에
   정확한 평가 날짜·최소 표본·승격 gate를 별도 등록한다. 기존 gate를 사후 완화하지 않는다.
7. Codex는 동일 경기 paired LL/Brier/적중률, calibration, 주 단위 CI, 리그/시즌,
   정보 커버리지와 픽 제공률을 검증한다. 새로운 미관측 표본·시점 증거가 부족하면 보류한다.

학습 결과 관측 시각, 실제 빌드 SHA(`local`로 저장됨), 과거 후보 일정과 운영 품질 게이트는
기존 manifest에서 완전히 인증되지 않는다. 이 분석을 운영 재현 또는 수익성 검증으로 부르지 않는다.
