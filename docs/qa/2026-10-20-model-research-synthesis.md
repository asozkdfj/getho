# 모델 연구 종합: 3시즌 오류 재분석과 실험 우선순위

2026-10-20 / Codex. 기존 산출물 기반 연구이며 기능 QA·운영 승인 아님.

## 이번에 실제로 한 일

기존 676경기 탐색을 넘어 시장 비교 실험의 저장된 경기별 예측을 읽어
2023-24~2025-26 **9,663경기**의 지표·오류 구간·무승부 AUC·시즌별 결과를 다시 계산했다.
7개 기존 실험의 판정도 조사하고 원본 해시를 집계 JSON에 보존했다.
자료 출처는 main `4f45edbe5647c731601b917945963cf696db7d7a`의 `ml/reports`다.
오늘 원격 main을 새로 조회한 것이 아니므로 이후 변경 상태에 관한 주장은 하지 않는다.

원본 파일: `ml/reports/backtest-market.predictions.jsonl.gz`.
저장 예측은 소수점 6자리여서 확률 합 오차 2e-6까지 허용하고 재정규화하지 않았다.
원본 학습·특성 계산은 다시 실행하지 않았다. 기존 보고서 운영 LL 0.997576465와
이번 0.997576454의 약 1.1e-8 차이는 저장 정밀도 수준이다.

## 1. 큰 시장 의견 차이에서 과신하는 패턴은 과거 자료에도 있다

| 분석 집합 | n | 운영 적중률 | 시장 적중률 |
| --- | ---: | ---: | ---: |
| 전체 | 9,663 | 51.18% | 52.74% |
| 최우선 결과가 다른 경기 | 1,078 | 28.76% | 42.67% |

불일치 경기의 운영-시장 LL 차이 +0.045173,
경기 시작 주 단위 paired bootstrap 95% 구간 [+0.032550, +0.057930].
117주, 4,000회, seed 20261019. 구간별 다중 비교 보정은 하지 않았으며 탐색 결과다.
실제 결정 시각이 없어 kickoff 주로 묶었다. 자동 출력의 decision_weeks 필드도 여기서는 kickoff 주다.

모델이 선택한 결과에 시장보다 10%p 이상 높은 확률을 부여한 경기:

| 시즌 | n | 모델 평균 확률 | 같은 결과의 시장 확률 | 실제 적중률 |
| --- | ---: | ---: | ---: | ---: |
| 2023-24 | 204 | 49.87% | 36.14% | 34.31% |
| 2024-25 | 247 | 50.59% | 37.09% | 36.84% |
| 2025-26 | 248 | 48.81% | 35.36% | 31.45% |
| 합계 | 699 | 49.75% | 36.20% | 34.19% |

큰 의견 차이를 가치 발견으로 간주하기 어렵다는 방향이 676경기 분석과 일치한다.
그러나 과거 시장 배당의 가용 시각이 불명확하다. 시장이 더 늦은 정보를 사용했을 가능성이 있어
같은 시각에서 모델이 확정적으로 열등하다는 검증은 아니다.
오류 원인이 부상·피로·전술 중 무엇인지는 이 자료로 판별할 수 없다.

## 2. 무승부: 확대된 자료가 확인해준 것과 수정해야 할 해석

| 지표 | 운영 | 시장 |
| --- | ---: | ---: |
| 평균 무승부 확률 | 23.82% | 24.77% |
| 실제 무승부율 | 25.65% | 25.65% |
| 무승부 Brier | 0.18947 | 0.18813 |
| 무승부 AUC | 0.55536 | 0.57111 |
| 최대 확률 60% 이상 집합의 무승부 AUC | 0.57124 | 0.61084 |

고확률 집합은 1,900경기, 실제 무승부 355개다. 운영 무승부 평균 확률 18.23%,
실제 18.68%로 가깝지만 순위 구분은 시장보다 약했다.

**이전 소표본의 AUC 0.416을 일반화하면 안 된다.**
676경기 중 고확률 86경기의 무승부 양성은 14개뿐이었다.
큰 표본에서는 AUC가 0.5를 넘으므로 '운영 무승부 순위를 뒤집으면 좋다'는 해석은 지지되지 않는다.
남는 연구 질문은 확률 일괄 상승이 아니라 조건별 위험 구분과 추가 정보의 가치다.

## 3. 기존 실험의 증거 지도

아래 LL 개선은 각 실험 자체 기준선 대비의 보고된 수치다. 표본이 다르므로
행끼리 직접 순위를 매기는 동일 경기 대결이 아니다.
시장 행 이외 후보들의 경기별 재학습·CI는 이번에 독립 재현하지 않았다.

| 후보 | 보고된 후속 LL 개선 | 판단 및 다음 행동 |
| --- | ---: | --- |
| 유효슈팅+마무리 | +0.005197 / 9,663경기 | 기존 연구 gate 통과. 가장 우선적으로 실제 입력 시각·공급자 차이를 보존한 미래 평가 |
| 시장 75%+운영 25% | +0.017623 / 9,663경기 | 운영보다 개선됐지만 시장 단독보다 LL 0.003040 나쁨. 혼합 자체를 개선으로 가정하지 않음 |
| 무승부 비율 보정 | +0.000302 / 9,452경기 | 기존 gate 실패, CI 0 포함. 반복 계수 탐색보다 조건부 정보 연구 |
| 순위·동기 대리변수 | +0.000092 / 9,452경기 | 검증에서 선택한 dead_rubber 기준. gate 실패. '의지' 점수 확대 우선순위 낮음 |
| 팀 일정 혼잡 | -0.001231 | 기존 gate 실패. 선수별 출전 부담 연구와 구분; 단순 팀 경기 수 효과를 가정하지 않음 |
| 로지스틱 확률 보정 | +0.000632 / 9,663경기 | 특수 보정 gate는 통과, 표준 개선 gate는 실패, CI 0 포함. 큰 성능 향상으로 표현하지 않음 |
| 선수 선발 전력 | 약 +0.0024 / 613경기 | 기존 작은 표본, 확정적 개선 아님. 데이터 가용성과 범위 확보가 우선 |

슈팅 후보도 같은 보고서의 시장 단독보다 LL이 약 0.015467 나쁘다.
여러 후보가 같은 2023~26 구간을 반복 사용했으므로 새 독립 확인 자료로 취급하지 않는다.
피로·선수·멘탈·전술 등 변수가 현실적으로 중요하다는 설명과 모델의 추가 예측력은 별개다.

## 4. 연구 자원을 어디에 쓸 것인가

### 먼저: 현재 가장 유망한 슈팅 후보를 제대로 확인

- 이미 선택한 후보를 유지하고 새 기간에서 운영·시장과 동일 경기 비교.
- 원본 공급자의 통계 정의, 양 팀 누락, 결과 가용 시각을 기록.
- 기존 shadow 기간/채택 기준을 이번 분석 때문에 바꾸지 않음.
- 시장 대비 추가 기여가 없으면 '자체 모델 개선'과 '시장보다 좋은 예측'을 구분해 보고.

### 다음: 시장에 없는 정보가 있는지 분석

- 같은 decision_at의 시장을 기준으로 선수 가용성·슈팅 정보의 추가 기여를 각각 측정.
- 새 변수 하나씩 추가한 모델을 고정하고 학습/선택/확인 구간을 분리.
- 시장 대비 확률 차이가 큰 사례의 입력 완전성과 모델 확률 오차를 추적.
- 베트맨 배당은 별도 수익 검증에 필요. 시장 정규화 확률 차이를 곧바로 EV라고 부르지 않음.

### 데이터 준비 후: 조건별 무승부·홈 이점

- 사전 예상 총득점, 양 팀 전력 차이, 홈/원정, 선수 가용성 등으로 오류를 설명할 자료 확보.
- 기존 무승부 보정 실험과 중복되는 계수 탐색을 피하고 새로운 입력의 기여를 검사.
- 현재 저장 시장 예측에는 예상 총득점·선수 상태가 없어 이 분석을 수행하지 못했음.
- 실제 결과를 보고 원인을 붙이거나 현재 API 자료로 과거 입력을 소급 채우지 않음.

### 보류: 복잡한 전술·멘탈 점수 및 구매 금액 최적화

이 변수들이 쓸모없다는 결론이 아니다. 관측 시각·정의·표본 없이 입력을 늘리거나
불확실한 확률로 구매 금액을 최적화하면 개선 여부를 판단하기 어렵기 때문이다.
확률 품질과 실제 제공 배당의 가치를 먼저 평가할 수 있어야 한다.

## 다음 실험이 제출해야 할 최소 자료

경기별 고정 ID, league/season, decision_at, 모델/학습/입력 해시, 각 입력의 observed_at,
동일 시각 시장 스냅샷, 세 결과 확률, 전체 후보 및 제외 사유, 결과 관측 이력.
원본 파일도 재현 가능한 접근 경로와 함께 보존한다.

주 평가 지표·최소 효과·표본 크기·기간·후보 수를 결과 확인 전에 고정한다.
LL/Brier, 무승부 AUC, 적중률, 제공률을 분리하고 구매 성과는 실제 배당이 있을 때 추가한다.
반복된 과거 탐색을 많이 했다는 사실 자체가 미래 성능 증거가 되지는 않는다.

## 재현

```powershell
python -m scripts.qa.analyze_historical_errors <source-repo>/ml/reports/backtest-market.predictions.jsonl.gz --out docs/qa/2026-10-20-historical-error-analysis.json
python -m pytest -q scripts/qa/test_historical_errors.py scripts/qa/test_draw_discrimination.py scripts/qa/test_prediction_errors.py scripts/qa/test_paired_market.py
python -m ruff check scripts/qa/analyze_historical_errors.py scripts/qa/test_historical_errors.py
```

같은 디렉터리에 위 7개 실험 JSON이 필요하다. Windows는 PYTHONUTF8=1 사용.
실제 저장 예측 재계산 완료, 테스트 10 PASS, Ruff PASS.
중복·잘못된 확률·반올림 허용, 시즌 선택 및 공동 실패 처리를 포함한다.
집계 JSON에 입력·스크립트·기존 보고서 해시를 기록했다.
