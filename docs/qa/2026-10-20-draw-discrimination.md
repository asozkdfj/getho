## 1. 시장과의 큰 차이는 현재 표본에서 과신으로 나타난다

모델이 선택한 결과 하나를 고정하고, 그 결과에 대한 두 확률과 실제 적중률을 비교했다.
시장 자신의 최우선 결과 적중률과 혼동하지 않는다. 구간은 탐색용이며 사전 등록된 검정이 아니다.

| 모델 확률 - 시장 확률 | n | 모델 평균 확률 | 같은 결과의 시장 평균 확률 | 실제 적중률 |
| --- | ---: | ---: | ---: | ---: |
| 0%p 미만 | 315 | 49.82% | 56.22% | 59.05% |
| 0~5%p | 171 | 47.70% | 45.27% | 49.71% |
| 5~10%p | 111 | 47.58% | 40.21% | 40.54% |
| 10%p 이상 | 79 | 48.60% | 34.28% | 32.91% |

10%p 이상 구간에서 모델은 실제 빈도보다 15.69%p 높고 시장은 1.37%p 높다.
시장과의 큰 의견 차이를 '좋은 기회'로 표시하기 전에 해당 차이에 추가 정보가 있는지
확인해야 한다. 반대로 0~5%p 구간에서는 모델 평균이 실제 빈도에 더 가깝다.
이 구간을 수익 전략으로 채택하거나 차이를 5%p로 잘라 쓰는 것은 허용되는 결론이 아니다.
조건부로 선택한 서로 다른 경기 집합이므로 구간 간 차이는 인과 효과가 아니다.

## 2. 무승부는 평균보다 순위 구분에서 개선 여지가 보인다

무승부 대 비무승부의 이진 평가다. Brier는 낮을수록, AUC는 높을수록 좋다.
AUC는 실제 무승부 경기에 더 높은 무승부 확률을 부여하는 순위 구분 능력이며
동률은 0.5점이다. 확률 보정이나 수익을 직접 측정하지 않는다.

| 지표 | 운영 | 시장 |
| --- | ---: | ---: |
| 평균 무승부 확률 | 24.23% | 24.85% |
| 실제 무승부율 | 24.70% | 24.70% |
| 무승부 이진 Brier | 0.18317 | 0.18182 |
| 무승부 AUC | 0.58471 | 0.61512 |

두 결정일 각각의 AUC도 운영/시장 0.5971/0.6172, 0.5479/0.6104였다.
두 날짜의 일관성은 여러 시즌에서 검증한 안정성을 뜻하지 않는다.

운영 무승부 확률로 같은 경기들을 나눈 구간별 실제 빈도:

| 무승부 확률 구간 | n | 운영 평균 확률 | 실제 무승부율 |
| --- | ---: | ---: | ---: |
| 20% 미만 | 82 | 18.06% | 18.29% |
| 20~25% | 330 | 22.77% | 22.73% |
| 25~30% | 210 | 26.96% | 26.67% |
| 30% 이상 | 54 | 31.96% | 38.89% |

낮은 세 구간의 평균은 실제 빈도와 가깝다. 30% 이상에서 과소평가가 보이지만 54경기
탐색 결과이므로 해당 구간 확률을 즉시 올리거나 재보정 계수를 학습하지 않았다.

운영 최대 확률 60% 이상 86경기에서는 실제 무승부 14개(16.28%)에 비해
운영 평균 무승부 확률은 18.90%, 시장은 18.74%였다.
따라서 앞선 '실패 24개 중 무승부 14개'는 무승부 확률이 전체적으로 너무 낮다는 증거가 아니다.
이 집합의 무승부 AUC는 운영 0.41567, 시장 0.60218로 차이가 크지만
양성 사례가 14개뿐이므로 순위를 뒤집는 정책이나 확정적인 결론을 만들지 않는다.

## 3. 무승부만 고치면 전체 성능 문제가 해결되는가?

전체 운영-시장 Log Loss 차이 +0.025307을 실제 결과별로 분해했다.
각 기여값은 해당 결과 경기의 손실 차이 합을 전체 676으로 나눈 값이므로 합산 가능하다.

| 실제 결과 | n | 전체 LL 차이에 기여 |
| --- | ---: | ---: |
| 홈승 | 307 | +0.014074 |
| 무승부 | 167 | +0.008844 |
| 원정승 | 202 | +0.002389 |

열세의 약 55.6%가 홈승 경기, 34.9%가 무승부 경기에서 발생했다.
이는 사후 결과별 손실 분해이며 예측 전에 홈승 경기만 골라낼 수 있다는 뜻이 아니다.
무승부 연구만으로 전체 격차가 해결된다고 가정할 수 없다.

## 후속 연구 계획

1. **시장 대비 잔여 정보:** 별도 새 기간에서 위 확률 차이 구간별 적중 빈도·LL·Brier를
   고정해 추적한다. 단순 시장 혼합이 좋다는 기존 근거도 부족하므로 혼합 가중치를 여기서
   최적화하지 않는다. 시장 입력 이후 추가 변수가 남기는 정보의 기여를 검증한다.
2. **무승부 위험 순위:** 이미 존재하는 무승부 후보 실험과 중복 여부를 확인한 뒤,
   사전 예상 총득점·전력 균형에 따른 조건별 오차를 다음 분석 대상으로 둔다.
   이번 manifest에 해당 입력이 없어 추정해 채워 넣지 않았다.
   새 후보는 동일 결정 시각의 시장 기준선과 AUC 및 적정 확률 점수를 함께 비교한다.
3. **홈승 결과에서의 손실:** 경기 전 홈/원정 전력 평가와 확률 분배를 연구한다.
   홈 이점·결장·피로가 원인이라는 증거는 없으므로 변수군별 추가 실험이 필요하다.
4. 기존 shadow 프로토콜은 유지한다. 새 분석 가설의 기간·표본·주 평가 지표를 별도
   사전 등록하고, 반복해서 본 이 자료로 후보를 최종 채택하지 않는다.

베트맨 배당과 실제 구매표는 사용하지 않았다. EV·수익률·조합 수익성은 미측정이다.
