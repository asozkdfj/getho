담당 Codex. 코드와 기존 실험 검토에 따른 제안이며 신규 후보의 성능 향상을 입증한 보고서가 아니다.
운영 기준은 main d6cef46의 Poisson + Elo v0.2.0, 보정 검토는 PR #10 233074c다.
모델 수정·승격·배포는 수행하지 않았다.

## 판단

정확도와 확률 품질을 높이려면 새 정보의 기여를 검증해야 한다. 기존 예측 확률을 높여 표시하거나
높은 확률 경기만 골라 적중률을 높이는 것은 전체 경기의 예측력 향상과 구분한다.
현재 최우선 후보는 의사결정 시점에 관측된 시장 확률, 다음은 선수 가용성 및 과거 경기력 데이터다.

시장 우위는 배당 수집 시각 불명인 과거 자료에서 관측한 것이다. 오전 9시 모델이 동일하게 좋아진다는
보장은 없다. 시장 단독이 가장 좋으면 정확도 우선 제품에서는 그것도 정당한 기준 모델 후보이며,
자체 모델을 섞는다는 이유만으로 성능이 좋아지지 않는다. 시장을 입력으로 사용한 예측과 같은 시장의
차이를 독립적인 가치 발견처럼 설명하지 않는다.

## 변수 설계

- 오전 9시 고정 예측과 선발 발표 후 갱신 예측을 별개 제품/평가로 관리한다. 오전 9시에는 공식 선발이
  알려지지 않았다면 예상 선발과 불확실성을 사용한다. 늦게 나온 선발로 아침 예측을 덮어쓰지 않는다.
- 전력: 단순 결장 인원보다 주전-대체 선수 차이, 포지션, 예상 출전 시간을 고려한다.
- 피로: 팀 전체 경기 수 대신 실제 출전 부담과 로테이션을 사용한다. 이동은 경기장 거리부터 시작하되
  실제 이동 경로·휴식과 같다고 주장하지 않고 대리 변수로 기록한다.
- 포메이션: 4-3-3 대 3-5-2 이름만 넣기보다 압박, 직접 전개, 공중볼, 세트피스, 역습 허용 등
  과거 경기에서 계산한 스타일을 양 팀 조합으로 시험한다. 포메이션/스타일 변화는 공표 시각을 지킨다.
- 멘탈·승리 의지: 임의의 0~100 점수를 만들지 않는다. 당시 순위와 잔여 경기로 계산한 강등/우승 상황,
  감독 교체, 실제 로테이션 등 관측 가능한 대리 지표만 쓴다. 기존 순위·동기 실험의 작은 이득을
  감안하면 우선순위는 낮다. 뉴스 요약을 검증 없는 확률 가중치로 사용하지 않는다.
- xG: 현재 모델이 출력하는 예상 득점과, 과거 슈팅 이벤트로 측정한 xG를 구분한다.
  후자를 새 입력으로 확보하는 제안이다. 미래 경기의 실제 xG는 입력에 사용하지 않는다.

## 모델 구조

먼저 현재 모델을 고정한 채 변수군을 하나씩 추가해 기여를 확인한다. 새 정보 없이 파라미터 조합만
늘리는 실험은 이미 반복 사용한 평가 구간에 과적합할 수 있다.
리그별 표본이 작으면 전체 리그 정보를 일부 공유하면서 리그 차이를 허용하는 계층 모형을 후보로 둔다.
단순 정규화 회귀를 먼저 기준으로 두고, 상호작용이 필요한 경우 트리 기반 후보와 동일 조건으로 비교한다.
Dixon–Coles 옵션은 이미 코드에 있으므로 신규 아이디어로 취급하지 않는다. 이변량 득점 분포는
무승부/언더오버 등의 오류 분석이 필요성을 보여 줄 때 제한된 후보로 시험한다. 복잡성이 개선 보장은 아니다.

## 다음 실험 순서 및 채택 기준

1. 시각 QA 수정 후 append-only 스냅샷과 전체 경기 manifest/제외 사유를 수집한다.
2. 같은 09:00 의사결정 시각의 운영·시장 단독·고정 결합을 나란히 저장해 비공개 병행 평가한다.
3. 선수 가용성과 xG의 데이터 커버리지를 조사하고 확보 가능한 변수군 하나부터 추가한다.
4. 후보 선택은 과거 학습/검증 구간에서만 진행한다. 이미 탐색한 2023-26은 새 holdout으로 부르지 않는다.
5. 기존 기준 유지: 검증 LL 개선≥.001, 후속 개선≥.002, 주 단위 paired CI 상한<0,
   Brier 비악화. 시장을 사용하는 후보는 같은 시각 시장 단독 대비 결과도 제출한다.
6. calibration, 적중률, 리그/시즌별 결과, 픽 제공률, 무추천일을 별도 보고한다.
   목표 표본은 예상 최소 효과와 과거 주별 변동으로 사전에 정하고, 좋은 수치가 나오는 날 임의로 종료하지 않는다.
7. 신호가 없으면 미채택한다. 테스트 결과를 보고 기준이나 평가 구간을 완화하지 않는다.
