# QA 후 모델 개선 검토: 적중률과 확률 품질

2026-10-21 / Codex. main 3f7a546의 저장된 xG 경기별 예측을 재분석했다.
기존 후보를 고정하고 오류 변화를 진단했다. 재튜닝·운영 변경·새 후보 선택 없음.
검증 2024-25 2,913경기, 후속 2025-26 2,916경기. 이미 사용한 구간의 탐색이다.
원본 xG CSV/학습 재실행은 없으며 kickoff+3시간 가용 가정의 한계를 유지한다.

## 확률 품질 향상과 적중률 향상은 다르다

| 후속 2,916경기 | 적중률 | Log Loss | Brier |
| --- | ---: | ---: | ---: |
| 운영 | 50.89% | 1.002903 | 0.598953 |
| 슈팅 기준 | 50.62% | 0.999865 | 0.597163 |
| xG 교체 | 50.72% | 1.001350 | 0.598079 |
| 슈팅+xG | 50.82% | 1.000181 | 0.597327 |

슈팅은 운영보다 LL/Brier가 좋지만 이 구간에서는 8경기 덜 맞혔다.
슈팅+xG도 운영보다 2경기 덜 맞혔다. 작은 차이의 유의성은 주장하지 않는다.
다른 기간에서 슈팅 후보가 개선된 기존 결과와 구분한다.
LL이 좋아졌다는 이유만으로 더 자주 맞힌다고 설명해서는 안 된다.

## xG가 바꾼 예측

| 슈팅 → 슈팅+xG | 검증 | 후속 |
| --- | ---: | ---: |
| 최우선 결과 변경 | 95 | 111 |
| 기존 오답을 정답으로 수정 | 39 | 47 |
| 기존 정답을 오답으로 변경 | 26 | 41 |
| 바꾸었지만 둘 다 오답 | 30 | 23 |
| 순증 적중 | +13 | +6 |

후속에서 정답에 부여한 확률이 좋아진 경기는 1,496개, 나빠진 경기는 1,420개다.
그러나 변화의 크기를 반영한 전체 LL은 0.000316 악화됐다.
개선 경기 수가 많다는 사실만으로 확률 품질 개선을 주장할 수 없다.

후속 LL 차이의 실제 결과별 기여는 홈승 +0.000386, 무승부 +0.000831,
원정승 -0.000901이다. 합계는 +0.000316이다.
무승부 AUC도 슈팅 0.54499 → 슈팅+xG 0.54343으로 개선되지 않았다.
이는 사후 설명이다. 실제 원정승 경기만 미리 골라 xG를 쓰는 규칙으로 전환할 수 없다.
기존 xG 미채택 결론과 같은 자료를 이용한 재튜닝 금지 원칙을 유지한다.

## 다음 연구 방향

1. 기존 슈팅 shadow 확인은 기간·후보·gate 그대로 유지한다. 미래 결과에서
   확률 품질, 같은 경기의 적중 순증, 제공률을 함께 보고한다.
2. 다음 별도 실험에는 사용자의 적중률 목표를 명시한다. 결과를 보기 전에
   동일 경기 top-1 적중률 차이, 주 단위 paired CI, 최소 효과, 표본 수를 고정한다.
   LL/Brier 악화 허용 범위도 사전에 정한다. 이번 결과 때문에 기존 gate를 바꾸지 않는다.
3. 다음 새 정보 후보는 선수 가용성이다. 주전/대체 선수 전력과 예상 출전 시간을
   결정 이전 자료로 계산하고 슈팅 기준 및 같은 시각 시장과 비교한다.
   효과를 입증한 것은 아니다. 수집량·누락·관측 시각 확인이 먼저다.
4. 아침 예측과 선발 발표 후 예측을 별도 평가한다. 추가 정보가 기존 오답을 얼마나
   고치는지 측정하되 아침 예측을 덮어쓰지 않는다. 배당/구매 가능 시각도 각각 보존한다.
5. 시장과 큰 의견 차이를 기회로 표시하기 전에 추가 정보의 기여를 미래 표본에서
   확인한다. 이견 경기를 제외해 제공률을 낮춘 성과는 전체 예측력 개선과 구분한다.

우선순위는 기존 슈팅 미래 평가 → 선수 가용성 데이터 준비 →
별도 사전 등록한 선수 후보/선발 갱신 비교다.
현재 자료로 효과 크기나 필요 표본을 임의로 약속하지 않는다.
베트맨 수익성은 별도 미검증이다.
