# 같은 시각 병행 기록 2: 슈팅 기반 전력 후보 (shadow-v2, 사전 등록)

이 문서는 shadow-v2 기록이 **하나도 없을 때** 고정합니다. 커밋한 뒤에는 후보 정의, 고정 계수, 평가 기간, 표본 기준, 판단 기준을
바꾸지 않습니다. 바꿔야 하면 새 프로토콜(shadow-v3)로 다시 등록합니다. shadow-v1은 그대로 계속 기록합니다.

## 왜 하나

슈팅 기반 전력 변수(`sot_and_finishing`, ADR-034)는 과거 데이터로 한 실험에서 표준 승격 기준을 통과했습니다.
후속 2023-26 구간에서 log loss를 +0.0052 개선했습니다. 하지만 그 후속 구간은 다른 실험에서 이미 본 기간입니다. 또 서비스 입력은
학습에 쓴 football-data.co.uk가 아니라 API-Football `match_statistics`입니다. 그래서 운영 모델을 바꾸기 전에,
**아직 오지 않은 경기**를 **서비스 입력 그대로** 오전 9시 결정 시각에 기록하고 한 번만 채점합니다.

## 무엇을 기록하나

- **시점:** shadow-v1과 같은 순간에 기록합니다. 오늘의 픽을 결정할 때(같은 `decided_at`, 같은 예측 `as_of`), 픽 시간대의 모든 경기에
  `protocol = shadow-v2`로 한 줄씩 남깁니다(`services/shadow_v2.py`).
- **후보** (`edge_ml.shadow_v2`):
  - `production`: 그 시각 픽이 쓰는 운영 예측의 확률
  - `market`: shadow-v1과 같은 배당 행에서 수수료를 비례 제거한 확률
  - `production_shots_v1`: 운영 예측에 저장된 기대 득점에 고정 계수와 슈팅 변수를 적용해, 운영 모델과 같은 방식으로 확률로 바꾼 것
- **슈팅 변수 입력** (`edge_ml.shots`, 실험과 같은 코드):
  - 같은 리그의 끝난 경기 중 킥오프 + 3시간이 결정 시각보다 이른 경기만 씁니다.
  - 양 팀 통계가 결정 시각까지 저장된 경기만 씁니다(`latest_statistics(as_of=결정 시각)`).
  - 팀별 최근 10경기를 쓰고, 리그 기준값은 최근 300경기로 냅니다. 입력값과 경기 수를 각 줄의 `forecasts.inputs`에 남깁니다.
- **고정 계수:** 실험의 모든 시즌(2019-20~2025-26, 9개 리그, 22,672경기)으로 한 번 맞춘 값입니다. 평가 기간 동안 다시 맞추지 않습니다.
  - own = (0.0611, −0.1881, −0.2342, −0.0861)
  - opponent = (0.1314, −0.0012, 0.0632, 0.2574)
  - 정확한 값은 `edge_ml/shadow_v2.py`에 있습니다.
- **제외와 사유:** shadow-v1과 같은 사유에 `insufficient_shot_history`를 더합니다(어느 한 팀이라도 쓸 수 있는 경기가 5경기 미만).
- **공개하지 않음:** 화면에 보이지 않고 픽에 영향이 없습니다. 기록이 실패해도 픽은 그대로 나오고, 실패는 픽 evidence의 `shadow_v2`에 남습니다.

## 평가 (한 번)

| 항목 | 값 |
| --- | --- |
| 평가 기간 | 결정일 **2026-11-02 ~ 2027-03-28** (21주) |
| 채점 대상 | 위 기간의 `recorded` 경기 중 결과가 난 경기. 연기·취소 경기는 따로 셉니다 |
| 채점 시점 | 기간이 끝나고 모든 경기 결과가 난 뒤 한 번. 그 전에는 `provisional`로만 표시하고 판단을 내지 않습니다 |
| 최소 표본 | 결과가 난 경기 **1,500**. 미만이면 "판단 불가"(`inconclusive`) |
| 신뢰구간 | 경기별 log loss 차이를 결정일 단위로 묶은 부트스트랩(4,000회, seed 20261102). 주 단위도 함께 보고 |

**표본 근거:**
- 과거 후속 구간에서 경기별 차이의 유효 표준편차(주 단위)는 0.081이었습니다.
- 효과가 과거와 같다면(+0.0052), 1,500경기에서 "CI 상한 < 0"을 만족할 확률은 약 70%, 1,800경기에서는 약 78%입니다.
- 이번 시즌 슈팅 통계를 모으는 리그(기본: 검증 리그)에서 21주 동안 1,500~1,900경기를 예상합니다.
- 효과가 과거보다 작으면 통과하지 못할 수 있습니다. 그 결과도 그대로 보고합니다.

## 판단 기준

**미래 경기 확인 통과:** `production_shots_v1`이 `production`보다 다음 세 가지를 모두 만족해야 합니다.
1. log loss 개선 ≥ 0.002
2. 결정일 단위 95% CI 상한 < 0
3. Brier가 나빠지지 않음

참고로만 보고하고 판단에 쓰지 않는 것: 시장 대비 차이(`market_vs_shots`), 제외 사유별 경기 수, 픽 범위 결과.

## 판단 이후

- **통과했을 때:** 운영 모델 0.3.0(슈팅 변수 포함) 교체를 제안할 수 있습니다. Codex 독립 QA와 사용자 승인이 먼저이고, 자동 반영은 없습니다.
- **통과하지 못했을 때:** 운영 모델은 그대로 둡니다. 원인(데이터 출처 차이, 효과 크기)을 따로 분석합니다.
- **데이터 출처:** API-Football과 football-data.co.uk의 유효 슈팅 차이는 `edge compare-shots`로 따로 확인합니다. 결과가 이 프로토콜을 바꾸지는 않습니다.
