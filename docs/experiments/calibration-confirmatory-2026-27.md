# 강팀 확률 보정 확인 실험 (2026-27, 사전 등록)

이 문서는 2026-27 시즌 결과로 채점하기 **전에** 고정합니다. 커밋 이후에는 규칙·보정식·데이터 범위를 바꾸지 않습니다.
바꿔야 하면 새 실험으로 다시 등록합니다.

## 왜 다시 하나

탐색 실험(`edge backtest-calibration`, 사전 등록 `cd8846f`, 실험 장부 7.5)의 후속 구간 2023-26은 그 전에 이미 본
기간입니다(시장 기준선 실험과 확률 구간 탐색이 이 실험의 동기였음). 그래서 독립 검증이 아니고, 그때 쓴 기준(G1·G2)도
표준 승격 기준보다 약했습니다(Codex QA M1). 탐색 실험의 결과는 **탐색 결과**로만 씁니다.

## 고정하는 것

| 항목 | 값 |
| --- | --- |
| 보정 방법 | `TopOutcomeCalibrator("logistic")`: 가장 높은 결과의 확률 p를 logit q = a + b·logit p로 바꾸고, 나머지 두 결과는 비율을 유지하며 1 − q를 나눔 |
| 보정식 | a = 0.016148, b = 1.167509 (`ml/reports/backtest-calibration.json`의 `frozen_map_for_confirmation`) |
| 학습 데이터 | 2019-20 ~ 2025-26, 9개 리그 22,671경기, 입력 SHA-256 `cb944ef9f0bf6ec38cfa5f27ee91e81b57853a5105444c8d38a0bd9456e321f9`, 마지막 결과 반영 가능 시각 2026-05-24 22:00 UTC |
| 다시 학습·재선택 | 하지 않음. 시즌 중에도 보정식은 위 값 그대로 |

## 채점 대상

- 리그: 탐색 실험과 같은 9개(de.1, de.2, en.1, en.2, es.1, fr.1, it.1, nl.1, pt.1)의 리그 경기.
- 기간: **킥오프 2026-10-19 00:00 UTC 이후**부터 2026-27 시즌 끝(2027-06-30)까지. 이 문서보다 먼저 결과를 볼 수 있었던
  시즌 초반 경기는 넣지 않습니다.
- 운영 확률(보정 전): 탐색 실험과 같은 방식(`backtest-market`의 운영 모델 walk-forward, 주 단위 재학습, 결과는 킥오프 3시간
  뒤부터 학습에 사용)으로 만든 경기별 확률. 서비스에 저장된 예측(`predictions`, 킥오프 전 입력·생성)은 있으면 참고로만
  같은 표를 냅니다.
- 결과 데이터: 공개 결과(football-data.co.uk 또는 Club Football Match Data)를 쓰고, 파일 SHA-256과 행 수를 결과표에 남깁니다.
  결과가 없는 경기(연기·취소)는 빼고 그 수를 적습니다.

## 채점 시점

- 9개 리그의 2026-27 마지막 경기가 끝난 뒤 **한 번** 채점합니다. 중간 결과로 실험을 멈추거나 바꾸지 않습니다.
- 채점 대상이 2,500경기 미만이면 결론을 내지 않습니다("판단 불가").

## 판단 기준 (둘 다 보고)

**표준 승격 기준.** 운영 모델 교체에 쓰는 기준입니다.

- 검증 개선 ≥ 0.001: 탐색 실험의 검증 2020-23은 +0.00048로 **이미 미달**입니다.
- 확인 구간 log loss 개선 ≥ 0.002.
- 주 단위 paired 95% CI의 상한 < 0.

검증 조건이 이미 미달이므로, 2026-27 결과와 관계없이 이 후보는 표준 기준을 통과할 수 없습니다. 확인 구간의 두 수치는 그래도
그대로 계산해 보고합니다.

**보정 기준.** 보정이 목적에 맞게 작동하는지 봅니다. 모두 2026-27 확인 구간 기준입니다.

- C1: log loss 개선 ≥ 0, Brier 개선 ≥ 0.
- C2: 운영 확률 기준 60% 이상 경기에서 |실제 적중률 − 보정 후 평균 확률| ≤ 0.015이고, 운영 확률의 같은 차이보다 작음.
- C3: 60% 미만 경기의 같은 차이가 운영 확률보다 0.005 넘게 커지지 않음.

**참고로만 보고(판단에 쓰지 않음):** 리그별·월별 log loss와 60% 이상 차이, 확률 구간표, 55%/65% 구간을 넘는 경기 비중,
하루 상위 3경기 조합의 확률 대 실제.
